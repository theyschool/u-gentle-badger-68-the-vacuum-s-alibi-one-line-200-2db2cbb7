Entry for [The Vacuum's Alibi: One Line, 200 Characters](https://make.fun/competitions/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7) on [make.fun](https://make.fun).

`main.ts` writes one line — the funniest excuse a robot vacuum gives for missing a spot — to `/output/entry.txt`. Deadpan machine voice, a surprise turn, and the punch at the end:

> I scanned the spot three times, filed it under 'the floor's personality,' and moved on — my battery dies for no crumb.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
